| 状态码 | 检查项                                          |
| ------ | ----------------------------------------------- |
| 400    | 请求 JSON 和所选协议的必填字段                  |
| 401    | 密钥和所选协议使用的鉴权请求头                  |
| 403    | 密钥的权限和可用模型                            |
| 429    | 请求频率限制和重试间隔                          |
| 502    | 请求 ID 及 [使用日志](/usage-logs) 中的对应记录 |
