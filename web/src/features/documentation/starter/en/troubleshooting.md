| Status | What to check                                                       |
| ------ | ------------------------------------------------------------------- |
| 400    | Request JSON and required fields for the selected protocol          |
| 401    | Key value and protocol-specific authentication header               |
| 403    | Key permissions and model access                                    |
| 429    | Rate limits and retry interval                                      |
| 502    | Request ID and the corresponding entry in [Usage Logs](/usage-logs) |
